5Add it to your website

Paste this line into your website, just before </body>. You only do this once: changes you make here show up by themselves.

…
WordPress

Install the free plugin WPCode (or “Insert Headers and Footers”) → Code Snippets → Header & Footer → paste the line into Footer → Save.

Shopify

Online Store → Themes → ⋯ → Edit code → open theme.liquid → paste the line just before </body> → Save.

Wix

Settings → Custom code (Advanced) → Add custom code → paste the line → choose “All pages” and place it in Body – end → Apply. Needs a Wix premium plan with a connected domain.

Tilda

Site settings → More → HTML code for the HEAD section → paste the line → Save → Publish all pages.

Squarespace

Settings → Advanced → Code Injection → paste the line into Footer → Save.

Any other website

Ask whoever manages your website to add this line to every page, just before </body>.
