You can request supported Hansora image, video, and audio generation inside ChatGPT by installing the Hansora integration, connecting your Hansora account, and asking it to use Hansora explicitly. Generation uses Hansora credits; access and tool behavior also depend on your ChatGPT account and workspace settings.

This Hansora-published guide follows the public Hansora setup page and official OpenAI documentation checked on October 16, 2026. Interface labels may change. Use the live setup page as the starting point if the buttons you see differ.

Understand what the integration does

Hansora exposes generation tools through the Model Context Protocol, or MCP. A compatible assistant can request a task from Hansora and return the result or its status to your conversation. That is different from asking ChatGPT to use a native image feature: the service handling the generation, available models, and billing are different.

Keep the creative brief in the conversation, but check which tool is being used before approving a paid task. Naming Hansora makes your intention clearer when several apps can generate similar media. Installing a connection does not turn every media request into a Hansora request automatically.

Connect Hansora to ChatGPT

  1. Open the Hansora integration guide and choose ChatGPT.
  2. Select Add Hansora to ChatGPT. The documented flow opens Hansora's plugin page in ChatGPT; select Install plugin if that option is available.
  3. Sign in to your Hansora account and review the access request. Approve the Hansora connection to continue.
  4. Use Try in chat or start a conversation with Hansora selected. Ask for available models and a quote before submitting a generation.

These steps describe the published setup flow, not a completed login test on every account type. Workspace restrictions or account availability may affect installation. If the integration is already installed, inspect its connection status before creating another entry.

Custom MCP connection, where available

The published server address is https://hansora.co/mcp. OpenAI's custom MCP server guide describes adding a server from ChatGPT Plugins, entering its URL, reviewing authentication, and installing the resulting plugin. Use this route only where your account permits it. Follow the Hansora sign-in flow; do not paste passwords or private tokens into a conversation.

Use a repeatable request sequence

For a paid creative task, keep four decisions explicit: discover a suitable model, quote the chosen settings, submit once you approve, then check the resulting task. Recheck the quote whenever the model, duration, resolution, sound, or quantity changes.

If the assistant returns only a text description, ask whether it actually invoked Hansora and whether it received a task identifier or media result. A written concept is not proof that a generation occurred. If a client cannot pass an attached reference to a tool, use its supported upload flow rather than assuming the file reached the provider.

Request an image with a clear spending boundary

Begin with discovery rather than an assumed model name. Ask the assistant to identify a currently available image model that supports the references and output controls you need. Availability can change, and a model's website controls may not appear identically in every connected client.

Use Hansora to create a vertical concept image for a fictional ceramic mug campaign. Show me a suitable available model, supported settings, and the credit quote first. Wait for my confirmation before generating.

After approving the quote, review the returned image for shape, branding, unwanted text, and composition. Save the approved result. If a reference is needed for the next stage, ask how the connected tool accepts it. Attaching a file to the chat does not establish that every tool can process that file type or size.

Turn the approved image into a video

Ask for image-to-video support using the approved image and a simple motion brief. Specify one main action, a preferred aspect ratio, and the intended use. Ask the assistant to verify supported duration and resolution rather than treating your preferences as capabilities the model must have.

Use this approved mug image as a reference for a slow camera move. Keep the mug shape stable. Check an available Hansora image-to-video model, supported duration, and the exact credit quote. Ask before submitting.

Generation may return a task identifier before the media is ready. Ask for the task's status instead of submitting the same request again immediately. A second submission may be a second paid job. Download the finished output and inspect the whole clip; a successful task status does not establish creative approval.

Keep ChatGPT access and Hansora billing separate

A ChatGPT subscription is not a Hansora credit pack. Check Hansora pricing for generation spending and your ChatGPT account for integration access. The public Hansora guide describes voice, music, and other media tools, but confirm current tool availability before planning a production sequence.

Review each quoted job, particularly when the assistant proposes multiple variations. A request for several images, a video, and narration can involve several billable operations. For budgeting context, read Alternatives to Multiple AI Subscriptions.

Troubleshoot the connection and outputs

If the assistant does not use Hansora, select the installed integration and name it explicitly. If authorization fails, inspect the connection in the client's settings and reconnect through the official flow. If a job fails, retain its task identifier and check the final status before retrying.

Frequently asked questions

Does this use ChatGPT's native video generation?

No. A Hansora tool request is handled by Hansora and its selected provider. Review the tool, model, and quote to identify the service being used.

Can I use any Hansora model immediately?

Ask the integration to check the current catalog and supported inputs. Availability and presentation can vary by provider and client.

How do I disconnect?

Remove or disconnect the Hansora integration in your client's settings. Review active connection controls in your Hansora account where available.
